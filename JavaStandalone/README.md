# ServEasy  (EN)
**- Under Development 🚧**  

## 🛠 Technologies Used:  
The ServEasy project was developed with the following technologies:  

- 💻 **Java** - Main programming language  
- 🖥 **Swing** - Graphical user interface  
- 🗄 **MySQL** - Database  
- 🔗 **JDBC** - Database connection  
- 🏗 **Apache NetBeans / IntelliJ IDEA** - IDEs used  
- 🌱 **Git & GitHub** - Version control  

## 👥 Development Team:  
- **Tiago Portilho**  

## 🎯 Software Objective:  
**ServEasy** is a restaurant management system that simplifies order handling, improves staff communication, and increases operational efficiency. The software allows restaurant owners and employees to manage orders, tables, and payments easily and intuitively.  

## 🔧 System Features:  

- ✅ **Editable Menu**  
- ✅ **Order & Kitchen Management**  
- ✅ **Revenue Control**  
- ✅ **Table Management**  
- ✅ **Digital Payment Options**  
- ✅ **Customer Feedback**
